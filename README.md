## About This Project

This is a responsive Todo List application built using React.js. It allows users to add tasks, mark them as completed, undo completed tasks, and delete tasks when they are no longer needed. Each task also includes a description field where users can write additional details.

The application uses React's `useState` hook to manage task data and input values, while JavaScript's `map()` and `filter()` methods handle task updates and deletion. Conditional styling visually distinguishes completed tasks from pending tasks. The responsive CSS layout makes the application adaptable to different screen sizes.

**Technologies Used:** React.js, JavaScript, HTML, CSS, and Vite.
